# Phase 3 PRD — 출결·수료·수료증

## 1. 목표

참가자가 인증된 상태에서 간단히 출석하고, 교육담당자가 출결을 보정하며, 승인된 규칙에 따라 수료 결과와 수료증을 자동 생성한다.

## 2. 범위

- 로그인한 참가자의 QR 또는 출석 코드 인증
- 교육담당자의 수동 출결 등록·수정
- 출석, 지각, 조퇴, 결석 상태
- 출석·지각은 수료, 조퇴·결석은 미수료로 판정
- 교육 종료 후 수료 결과 자동 확정
- 수료자 PDF 수료증 생성, 비공개 저장, 이메일 발송
- 수료 결과와 수료증 조회·다운로드

## 3. 출결 흐름

1. 교육담당자가 차수의 출석 인증을 시작한다.
2. 로그인한 참가자가 QR 또는 코드를 통해 본인 출석을 기록한다.
3. 교육담당자가 예외 참가자의 상태를 수동 보정한다.
4. 차수 종료 후 시스템이 출결 상태를 기준으로 수료 여부를 판정한다.
5. 교육담당자가 결과를 확인하고 필요한 보정을 마친다.

## 4. 수료증 정책

- 발급 대상: 해당 차수 수료자
- 발급 시점: 교육 종료와 수료 확정 후
- 발급자: `한국후지필름비즈니스이노베이션㈜`
- 서명과 직인은 표시하지 않는다.
- 별도 검증 페이지와 수료증 번호는 제공하지 않는다.
- 과거 수료 결과 업로드 건에는 수료증을 생성하지 않는다.

## 5. 인수 기준

- 비로그인 사용자는 QR·코드 출석을 기록할 수 없다.
- 참가자는 본인이 승인된 차수에만 출석할 수 있다.
- 담당자가 출결 상태를 수정할 수 있고 변경 기록을 남긴다.
- 출석·지각과 조퇴·결석의 수료 판정 규칙이 일관되게 적용된다.
- 수료자에게 PDF 수료증이 생성·저장되고 발송 대상이 된다.
- 참가자와 담당자가 권한 범위 내에서 결과와 수료증을 확인한다.
