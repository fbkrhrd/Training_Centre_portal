# Phase 2 PRD — 교육과정·차수·신청 운영

## 1. 목표

교육담당자가 교육과정과 차수를 직관적으로 개설하고 참가자를 모집·배정하며, 참가자가 PC와 모바일에서 교육을 찾고 신청 상태를 확인할 수 있게 한다.

## 2. 범위

- 1단계 교육 카테고리
- 전체 참가자에게 공개되는 교육과정 목록
- 교육과정 기본 정보와 담당 교육담당자 지정
- 차수별 단일 일시, 운영 방식, 장소 또는 접속 링크, 정원, 신청·취소 기간
- 대면, 온라인, 혼합 운영 방식
- 참가자 직접 신청과 교육담당자 배정
- 모든 직접 신청에 대한 교육담당자 승인
- 수동 대기자 승급
- 일정 중복과 기존 수료자의 재신청 차단
- 취소 기한 이후 교육담당자만 취소 가능
- 관리자 전체 조회, 교육담당자 담당 과정 조회·관리

## 3. 핵심 사용자 흐름

### 3.1 교육 개설

1. 교육담당자가 카테고리와 교육과정을 등록한다.
2. 과정에 차수를 추가하고 하나의 교육 일시를 입력한다.
3. 운영 방식에 따라 장소와 온라인 링크를 설정한다.
4. 정원, 신청 기간, 취소 기한, 기본 알림 시점을 설정한다.
5. 게시 후 참가자 교육과정 목록에 노출한다.

### 3.2 참가자 신청

1. 참가자가 공개 교육과정과 차수를 검색한다.
2. 시스템은 일정 중복과 기존 수료 여부를 확인한다.
3. 정원 내 신청은 승인 대기, 정원 초과 신청은 대기 상태가 된다.
4. 교육담당자가 승인 또는 반려한다.
5. 상태 변경 결과를 포털과 이메일 알림 대상으로 기록한다.

### 3.3 담당자 배정과 취소

- 교육담당자는 참가자를 차수에 직접 배정할 수 있다.
- 참가자는 취소 기한 전까지 직접 취소할 수 있다.
- 취소 기한 이후에는 교육담당자가 취소한다.
- 빈자리가 생겨도 대기자는 자동 승급하지 않으며 담당자가 선택해 승급한다.

## 4. 주요 상태

- 차수: 작성, 모집 중, 모집 마감, 운영 완료, 취소
- 신청: 승인 대기, 승인, 반려, 대기, 취소

## 5. 인수 기준

- 교육담당자가 단일 일정의 차수를 개설·게시·수정할 수 있다.
- 참가자가 PC와 모바일에서 차수를 찾아 신청할 수 있다.
- 모든 직접 신청이 교육담당자 승인 절차를 거친다.
- 일정 중복과 수료자의 반복 신청이 차단된다.
- 대기자 승급과 기한 후 취소가 담당자 권한으로 처리된다.
- 역할과 담당 과정 범위에 따라 조회·수정 권한이 제한된다.
