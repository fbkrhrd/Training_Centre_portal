# Phase 4 PRD — 알림·자료·이력·운영 자동화

## 1. 목표

반복되는 교육 운영 안내, 콘텐츠 번역, 자료 배포, 과거 수료 결과 반영, 운영 데이터 내보내기와 감사 보존을 자동화해 교육담당자의 수작업을 줄인다.

## 2. 범위

### 2.1 알림

- 이메일과 포털 내 알림
- 차수별 알림 시점 설정, 기본값 D-7·D-1
- 일정, 장소, 온라인 링크 변경 시 자동 알림
- 신청 승인·반려·대기·취소 상태 알림
- Microsoft Graph 어댑터 우선, SMTP 대체 어댑터, 개발 로그 어댑터

### 2.2 한국어·영어 콘텐츠

- 운영자가 입력한 한국어 교육 콘텐츠를 OpenAI로 영어 자동 번역
- 번역 완료 즉시 영어 화면에 게시
- 운영자가 영어 문구를 직접 수정 가능
- 번역 실패 또는 미존재 시 한국어 원문 표시

### 2.3 교육 자료

- Supabase Storage 비공개 버킷 파일
- 외부 링크 등록
- 파일당 최대 50MB
- Office 문서, PDF, 이미지, ZIP 허용
- 승인 또는 배정된 참가자만 필요한 자료에 접근

### 2.4 과거 이력과 내보내기

- 과거 데이터는 수료 결과만 업로드
- 과거 수료 결과로 수료증은 생성하지 않음
- 운영 데이터 Excel·CSV 내보내기

### 2.5 감사와 운영

- 주요 관리 작업 감사 로그 1년 보관
- Vercel Cron 기반 알림·정리 작업
- Supabase 기본 백업 외 별도 백업 기능은 MVP 범위에서 제외
- 관리자 대시보드: 오늘 운영과 모집 현황
- 참가자 대시보드: 예정 교육과 교육 이력

## 3. 보안과 장애 처리

- 자료는 공개 URL이 아닌 권한 확인 후 단기 서명 URL로 제공한다.
- OpenAI, Microsoft, SMTP, Cron 비밀값은 서버 전용 환경변수로 관리한다.
- 번역·메일 전송 실패는 재시도 가능한 작업 상태로 기록한다.
- 동일 알림이 중복 발송되지 않도록 작업별 고유 키를 사용한다.
- 감사 로그는 일반 운영 화면에서 수정·삭제할 수 없다.

## 4. 인수 기준

- 기본 D-7·D-1 및 차수별 사용자 지정 알림이 중복 없이 실행된다.
- 핵심 정보 변경 시 대상 참가자에게 포털·이메일 알림이 생성된다.
- 한국어 콘텐츠가 자동 번역되고 운영자가 영어 문구를 수정할 수 있다.
- 승인된 사용자만 비공개 자료에 접근한다.
- 과거 수료 결과를 검증 후 업로드하고 수료증은 만들지 않는다.
- 운영 데이터를 Excel·CSV로 내려받을 수 있다.
- 주요 관리자 작업을 1년 감사 로그로 조회할 수 있다.
